# Companion AI

Build a production-ready AI chatbot exactly like ChatGPT.

Requirements:

- Use Next.js 15 (App Router), TypeScript, Tailwind CSS.

- Use my existing backend APIs. Do not create fake APIs.

- Build a premium dark UI similar to ChatGPT and Claude.

- Every feature must be fully functional.

Features:

1. Beautiful landing page

2. Authentication (Sign In, Sign Up, Forgot Password)

3. Chat Dashboard

4. Sidebar with conversation history

5. Create, Rename, Delete chats

6. Search conversations

7. Streaming AI responses (typing effect)

8. Markdown support

9. Syntax highlighting for code

10. Copy message

11. Edit message

12. Regenerate response

13. Stop generation button

14. Auto scroll

15. Model selector

16. Support:

   - OpenAI

   - Anthropic (Claude)

   - Gemini

   - Groq

   - DeepSeek

   - Mistral

   - OpenRouter

18. Image upload

19. PDF upload

20. Drag & Drop files

21. Chat settings

22. Temperature slider

23. Max Tokens

24. System Prompt

25. User profile

26. Theme switcher (Dark/Light)

27. Mobile responsive

28. Loading skeletons

29. Toast notifications

30. Error handling

31. Keyboard shortcuts

32. Token usage display

33. Cost estimation

34. Real-time streaming via WebSocket/SSE

35. Conversation export

36. Conversation import

37. Admin Dashboard

38. Analytics

39. User management

40. Production-ready architecture

Rules:

- Never use mock data.

- Never use placeholder components.

- Never leave TODO comments.

- Every import must exist.

- Every component must compile.

- Every page must work.

- Fix all TypeScript and ESLint errors automatically.

- If dependencies are missing, install and configure them.

- Connect everything to the existing backend.

- Do not overwrite existing working files unless necessary.

- Continue building until the entire application is complete.

When you hit the response limit, stop with exactly:

=== CONTINUE NEXT FILE ===

In the next response, continue automatically from the next unfinished file without repeating previous work.
